## 📋 Phase 1.4: 인터랙티브 요구사항 수집

### 6개 카테고리 질문

#### 1️⃣ 기능 범위 명확화

**질문**:
```
이 기능의 핵심 목표는 무엇인가요?

1. 신규 기능 추가
2. 기존 기능 개선
3. 버그 수정
4. 리팩토링
```

**목적**: 작업의 성격을 파악하여 적절한 계획 수립

---

#### 2️⃣ 사용자 시나리오

**질문**:
```
주요 사용자는 누구이며, 어떤 상황에서 이 기능을 사용하나요?

최소 2개의 구체적인 사용 사례를 설명해주세요.

예:
- "관리자가 대시보드에서 사용자 목록을 필터링할 때"
- "일반 사용자가 자신의 프로필을 업데이트할 때"
```

**목적**: 실제 사용 맥락 이해, 엣지 케이스 파악

---

#### 3️⃣ 기술적 제약사항

**질문** (다중 선택):
```
다음 중 고려해야 할 제약사항이 있나요? (여러 개 선택 가능)

1. 특정 라이브러리 사용 필수
2. 기존 API 호환성 유지
3. 성능 요구사항 (응답 시간, 처리량)
4. 보안 요구사항
5. 레거시 시스템 연동
```

**후속 질문** (선택한 항목에 따라):
```
[보안 요구사항을 선택한 경우]
보안 요구사항을 구체적으로 설명해주세요.
예: "JWT 토큰 필수", "관리자만 접근 가능"
```

**목적**: 기술적 제약 조건 파악, 아키텍처 결정에 반영

---

#### 4️⃣ 우선순위 및 범위

**질문**:
```
이번 구현에 포함될 기능을 우선순위별로 분류해주세요.

🔴 필수 (MUST HAVE): 반드시 포함되어야 하는 기능
   예: "사용자 로그인", "비밀번호 암호화"

🟡 권장 (SHOULD HAVE): 가능하면 포함하고 싶은 기능
   예: "소셜 로그인", "비밀번호 재설정"

🟢 선택 (NICE TO HAVE): 시간이 있으면 추가할 기능
   예: "2FA 인증", "로그인 이력 조회"
```

**목적**: 범위 명확화, MVP vs 전체 기능 구분

---

#### 5️⃣ 성공 기준

**질문**:
```
이 기능이 성공적으로 구현되었다고 판단하는 기준은 무엇인가요?

측정 가능한 지표를 알려주세요:
- 테스트 커버리지: ___%
```

**목적**: Quality Gate 정의, 완료 기준 명확화

## 📝 Phase 4: 사용자 피드백 및 계획 승인

### PLAN.md 요약 제시

**형식**:
```
✅ 구현 계획을 작성했습니다.

## 요약
- 기능: 프로필 사진 업로드 및 관리
- Phase 개수: 4개
- 예상 소요 시간: 6-9시간
- 주요 기술: multer, sharp, AWS S3

## Phase 구성
1. Phase 1: 파일 업로드 기본 구조 (1-2h)
   - multer 설정, 파일 검증 (크기, 형식)
   - 로컬 저장소 임시 구현

2. Phase 2: 이미지 처리 (2-3h)
   - sharp로 리사이징, 최적화
   - 썸네일 생성

3. Phase 3: S3 통합 (2-3h)
   - AWS S3 업로드
   - 이미지 URL 관리

4. Phase 4: 권한 제어 및 검증 (1h)
   - 관리자 삭제 권한
   - 본인 프로필만 수정 검증
   - 부적절한 이미지 신고 기능 (선택)

## 주요 아키텍처 결정
- multer: 파일 업로드 미들웨어 (Express 호환성)
- sharp: 이미지 리사이징 (빠른 성능, 메모리 효율적)
- S3: 확장성, CDN 통합 가능
- 권한 체크: authMiddleware + 추가 검증

## 제약사항
- 파일 크기: 5MB 이하
- 형식: JPG, PNG만 허용
- 권한: 관리자 삭제, 본인 프로필만 수정

## 위험 요소
- S3 비용: 사용량에 따라 증가 가능 → CloudFront CDN 고려
- 악의적 파일 업로드: 파일 형식 검증, 바이러스 스캔 권장

---

전체 계획은 다음 파일에 있습니다:

이 계획으로 진행해도 될까요?
수정이 필요한 부분이 있으면 알려주세요.
```

### 반복 제한 및 에스컬레이션

**3회 수정 초과 시**:
```
⚠️ 계획 수정을 3회 반복했습니다.

현재 상태:
- 초기 요청: "프로필 사진 업로드"
- 1차 수정: Phase 순서 변경
- 2차 수정: 테스트 커버리지 90%로 상향
- 3차 수정: 신고 기능 Phase 분리

현재 계획:
- Phase 개수: 5개
- 예상 소요: 7-10시간
- 주요 변경: 신고 기능 별도 Phase, 커버리지 90%

다음 중 선택해주세요:

1. ✅ 현재 계획으로 진행 (승인)
   → 더 이상 수정 없이 Implementer로 진행

2. 🔄 요구사항을 처음부터 다시 정리
   → Phase 1부터 재시작, 인터랙티브 질문 다시 진행

3. ⏸️ 일단 중단하고 나중에 다시 시작
   → 현재 PLAN.md 저장 (초안), 나중에 재개 가능

어떻게 하시겠습니까? (1, 2, 또는 3)
```

**선택에 따른 동작**:
- **1 (승인)**: 바로 완료 처리, Implementer 대기
- **2 (재시작)**: Phase 1.4부터 모든 질문 다시 진행
- **3 (중단)**: PLAN.md에 "Status: 🟡 Draft" 표시하고 저장
